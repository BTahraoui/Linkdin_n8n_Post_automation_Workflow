# Outputs Examples

This folder contains example outputs from the LinkedIn n8n Auto-Poster workflow.

## 📄 What You Might Find Here

- **Text posts**: Example LinkedIn posts generated by the workflow
- **Images**: Sample images produced by FLUX.1 Schnell via Cloudflare Workers AI
- **Data snapshots**: Sanitized exports of workflow static data (for demonstration only)

## 🔐 Important: No Credentials

Never commit actual credentials, API keys, or sensitive data to this folder.
All examples should be sanitized or synthetic.

## 📂 Suggested Naming Convention

- `post-YYYY-MM-DD-HH-MM.txt` - LinkedIn post text
- `image-YYYY-MM-DD-HH-MM.png` - Generated image
- `staticdata-YYYY-MM-DD.json` - Sanitized static data snapshot
- `run-summary-YYYY-MM-DD.md` - Narrative summary of an interesting run

## 🎯 Purpose

These examples help new users understand:
- What kind of content the workflow produces
- The quality and style of generated posts and images
- How the anti-repeat mechanism works over time
- Typical failure modes and how they appear in logs

## 🙏 Contributing Examples

If you'd like to share example outputs:
1. Run the workflow a few times
2. Pick interesting or representative results
3. Sanitize any potentially sensitive information (though the workflow shouldn't produce credentials in outputs)
4. Add the files to this folder
5. Update this README with descriptions if helpful
6. Submit a pull request

> 💡 Remember: the workflow is designed to avoid generating sensitive information in outputs, but always double-check before committing.
