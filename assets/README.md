# Assets Directory

This directory contains static assets used by the project.

## 📁 Folder Structure

```
assets/
├── architecture/   # Diagrams and architectural drawings
│   └── workflow-diagram.png   # Main workflow diagram (n8n export)
├── outputs/        # Example outputs from workflow runs
│   └── README.md     # This file - describe what you might find here
└── # (future) templates/, icons/, etc.
```

## 🖼 Architecture

The `architecture/` folder contains visual representations of the workflow:
- `workflow-diagram.png`: The original diagram exported from n8n showing all nodes and connections

## 💾 Outputs

The `outputs/` folder is intended for:
- Example LinkedIn posts generated by the workflow
- Sample images produced by FLUX.1 Schnell
- Log exports or static data snapshots (for demonstration only - **never** include real credentials)

> 🔒 **Never** commit actual credential-containing files or sensitive data to this folder.

## 📤 Usage

When demonstrating the workflow:
1. Run a few executions
2. Copy interesting outputs (text posts, images) to `assets/outputs/`
3. Add descriptions in this README or create new markdown files
4. Commit the examples to show potential users what the workflow produces

## 🎨 Example Content

You might find:
- `example-post-2026-06-19.txt` - A sample LinkedIn post
- `example-image-2026-06-19.png` - The corresponding FLUX-generated image
- `static-data-example.json` - A sanitized snapshot of workflow static data

Remember: always sanitize any outputs before committing!
