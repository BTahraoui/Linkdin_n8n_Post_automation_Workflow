# Credits

> This project builds on the work of many excellent open-source projects, services, and communities.

## 🛠 Core Technology

- **[n8n](https://n8n.io)** – The fair-code workflow automation platform that makes this possible
- **[OpenRouter](https://openrouter.ai)** – Unified API for accessing LLMs (we use DeepSeek models)
- **[Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/)** – Serverless GPUs running FLUX.1 Schnell
- **[LinkedIn Marketing API](https://learn.microsoft.com/en-us/linkedin/marketing/)** – For publishing posts to profiles and pages
- **[Slack API](https://api.slack.com/)** – For workflow notifications and monitoring

## 🤖 AI Models

- **DeepSeek v4-flash** (`deepseek/deepseek-v4-flash`) – Fast, efficient LLM for LinkedIn post writing
- **DeepSeek chat** (`deepseek/deepseek-chat`) – Stronger reasoning LLM for image prompt engineering
- **FLUX.1 Schnell** (`@cf/black-forest-labs/flux-1-schnell`) – Lightning-fast text-to-image model from Black Forest Labs
